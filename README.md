# NumberGuessingGame
A simple NumberGuessing Game Using Java Language.
The user has to guess a number between 1 and 100, and they are given 5 attempts per round.

## How to Play:
* A random number is selected between 1 and 100.
* You have some attempts to guess the correct number.
* After each guess, you will be told whether the number is greater or smaller than your guess.

## How to Run:
* Download or clone this repository.
* Open the 'NumGuess.java' file in an IDE like Eclipse.
* Run the file to start playing the number guessing game.
